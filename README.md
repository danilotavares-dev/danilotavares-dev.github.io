# Jardim Digital | Danilo Lima Tavares

Bem-vindo ao repositório do meu espaço pessoal na internet. Diferente de um portfólio tradicional e engessado, este é um "Jardim Digital" e laboratório de experimentação. Um ambiente focado em *scrollytelling* para documentar minha evolução na Engenharia de Software e meus projetos.

## Tecnologias Utilizadas
- **[React](https://react.dev/) + [Vite](https://vitejs.dev/):** Para uma fundação rápida e moderna.
- **[Tailwind CSS v4](https://tailwindcss.com/):** Estilização utilitária e design responsivo.
- **[Framer Motion](https://www.framer.com/motion/):** Motor principal para as animações baseadas no scroll da página.
- **[Biome](https://biomejs.dev/):** Ferramenta ultrarrápida em Rust para formatação e linting dinâmicos.

## Estrutura do Projeto
A interface abandona a navegação tradicional em favor de uma rolagem contínua dividida em:
- **Hero:** Apresentação interativa de impacto.
- **Achievements:** Espaço detalhando arquiteturas de projetos (foco em Full-Stack, IA e DevOps).
- **Culture:** Meu hub pessoal de referências, livros e filmes.
- **Insights:** Anotações e reflexões sobre tecnologias de ponta, como machine learning e computação quântica.
